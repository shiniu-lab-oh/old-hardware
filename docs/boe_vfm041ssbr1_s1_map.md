原始来源：[Segment Mapper 记录](../examples/pt6312-test/SEGMENT_MAPPING.md)。
本表由用户提供的 64 状态实测结果整理，未用常规屏接线推测映射。
API position 0 / 1 / 2 / 3 对应本表 Physical Digit1 / 2 / 3 / 4。
数字从左至右的最终呈现由 1234 实机验收确认，不另行猜测物理顺序。

UNUSED 是当前 Profile 对“无可见显示”的标记，保留这些位以便追溯；Renderer 始终写零。

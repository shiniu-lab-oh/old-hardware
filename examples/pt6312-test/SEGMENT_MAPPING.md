# PT6312B VFD 实测 Segment Map

正式型号与归档：[BOE VFM041SSBR1-S1 Profile v0.1 Map](../../docs/boe_vfm041ssbr1_s1_map.md)。
本文件继续保留用户原始观测；正式表增加 Physical Digit、Segment、Notes 与 UNUSED 标记。

来源：用户使用 Segment Mapper v0.1 对当前 PT6312BLQ 四位 VFD 前面板逐 bit 实测。
测试模式：4 digit × 16 segment（0x00）；扫描 RAM 0x00～0x07，共 64 状态。
Digit1～Digit4 沿用用户实测编号。

## 标准七段命名

```text
       A
     ─────
  F │     │ B
    │  G  │
     ─────
  E │     │ C
    │     │
     ─────
       D
```

A：顶部；B：右上；C：右下；D：底部；E：左下；F：左上；G：中间横段。

## 映射摘要

| 实际显示 | State | RAM | Bit |
| --- | --- | --- | --- |
| Digit1-A～G | 0～6 | 0x00 | 0～6 |
| Digit2-A～G | 16～22 | 0x02 | 0～6 |
| Digit3-A～G | 32～38 | 0x04 | 0～6 |
| 中间冒号（Colon） | 39 | 0x04 | 7 |
| Digit4-A～G | 48～54 | 0x06 | 0～6 |

State 与地址的换算：`addr = state / 8`，`bit = state % 8`，`value = 1 << bit`（整数除法）。

冒号按本次实测记录为单一映射 `RAM 0x04 / bit7`，不拆分或猜测 Colon-top、Colon-bottom 的独立地址。
“无可见显示”仅表示本次测试未观察到点亮，不据此断言芯片引脚未连接或该 bit 永远无用途。

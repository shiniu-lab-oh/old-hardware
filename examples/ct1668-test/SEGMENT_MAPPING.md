# 康佳 SDC251 前面板段位实测记录

记录日期：2026-09-07。来源：用户对逐 bit 扫描的现场观察。
条件：独立 3.3V 供电，显示模式 `0x00`（TM1668 4 GRID / 13 SEG 假设），
亮度 0，每次清空 14 字节后仅设置一个 bit。

CT1668 compatibility assumption：协议按 TM1668 实现，未确认完全兼容。
下列映射来自这块面板的实测，不是预设的通用七段段码。
第 1～4 位沿用用户编号。本轮 112 个 bit 的可见响应已记录完毕；
“无可见变化”仅描述当前测试结果，不等于未连接或任何模式下都无作用。

C1、C3、C5、C7、C8、C9、CA、CB、CC、CD 的 bit0～bit7：
用户确认均无可见变化，共 80 个 bit。
用户已进一步确认：C2 bit1～bit6 与 C0 相同，第 3 位 C4、第 4 位 C6
也是相同排列。因此四位 bit0～bit6 均已实测确认，按常见段名记为
a、b、c、d、e、f、g；相应掩码为 01、02、04、08、10、20、40。
这套排列来自实测，后续可据此实现数字编码；尚未添加数字显示 API。
C0/C4/C6 的 bit7 均已确认无可见变化，共 3 个 bit。
全 FF 时已观察到四个 8 和冒号亮，小数点未亮；原因未确定。
此轮 RAM 扫描未找到状态 LED 位。随后用户确认绿灯由当时临时编号 pin6
（正式 J1 Pin 3）/ GPIO33 高电平控制，
红灯为 POWER 指示，不做软件接管；状态灯不纳入此数码管段位表。

## 本轮结果和范围

本轮扫描共 112 个 bit：四位各 7 段，加冒号 1 个控制位，共 29 个 bit
有可见响应；另外 83 个 bit 均无可见变化。

对应各 RAM 字节的已确认可见位掩码（按 C0～CD 顺序）：

```text
7F 00 FF 00 7F 00 7F 00 00 00 00 00 00 00
```

后续可根据此实测映射实现四位数字及独立冒号控制，普通显示先将其余位保持为 0。
当前驱动仍保留全部 14 字节原始 RAM 接口，以便继续实验。
在当前 3.3V、模式 0x00、亮度 0 的测试中，未找到小数点及两颗状态 LED
的控制位。不能由此推定它们未连接、损坏或一定由当时临时编号 pin5/pin6
（正式 J1 Pin 4/Pin 3）控制。
此后键盘读取及七个实体按键已经验证，见 KEY_MAPPING.md。
电气规格和其他显示模式尚未验证，CT1668 compatibility assumption 仍然保留。
状态 LED 路径继续记录于 LED_MAPPING.md。
